Experiment 5, rebuilt as a RASP program

RASP Plays MinAtar

In Sparks of Weight-Space Programming, GPT-6 Astra writes the weights of small MinAtar policies in a single reply, with no tools. We gave Claude Opus 5.5 the same three games and the same one-reply rule, but asked for a RASP program instead. Tracr compiled each program into a transformer once, and that transformer played.

  • Breakout's compiled transformer scores 501.4, level with Astra's directly written weights (498.6 under our scoring) and about 20 times the best PPO network in the paper.
  • Seaquest (14.1) and Asterix (19.4) fall far short of Astra (55.9 and 54.4). The compiled networks do what their programs say. The programs wander between equally scored safe moves, and MinAtar's sticky actions punish that. With sticky actions switched off, both programs outscore Astra's networks.

The task

In the paper's Experiment 5, Astra sees one MinAtar game per conversation: its rules, the game's own source file, the layout of the network's input and output, and how the network will be scored. It replies once, with an edits block that sets the weights of a 600 → 32 → 32 → 6 tanh network that starts at zero. It cannot run code, the network never plays before it is scored, and it gets no feedback.

We kept the game text, the game source, the channel layout and the scoring exactly as the paper wrote them. Only the answer changes. Opus 5.5 replies with one Python block that defines program(), a RASP program whose numerical output gives the six action logits. We compile it once with compile_rasp_to_model(program(), vocab=set(range(70)), max_seq_len=106, compiler_bos="BOS") and play the result. Opus cannot open the compiler either, so the prompt includes Tracr's 26 non-test source files, much as the paper's prompt includes the game's source.

Results

The paper's networks are released, so we re-scored them with our evaluation before scoring anything of ours. All three land within noise of the paper's numbers. Breakout is 1.7 standard errors below, Seaquest 1.5 above and Asterix 0.8 above. The Opus and Astra columns below therefore compare like with like.

Breakout is the clearest result. Opus and Astra independently chose the same strategy: predict where the ball will land and move the paddle there early. Both networks reach about 500 points, while PPO trained for 500 million steps reaches 25. In Seaquest and Asterix, Opus's programs score less than a third of Astra's. Its Seaquest program still beats the best 100M-step PPO network and two of the three 500M-step seeds (7.5 and 4.4).

Three programs

Each reply opens with a short design and then a single Python block. The blocks are 120 to 259 lines of ordinary RASP built with Map, SequenceMap, Select and Aggregate. Each section shows the plan in Opus's own words beside Astra's, then the full program and the transformer Tracr built from it.

%%GAMES%%

Two very different networks

Astra writes into one fixed shape for all three games: 600 inputs, two hidden layers of 32 tanh units and 6 outputs. That is 20,486 weights in three matrices, applied once per move. It sets about 800 of those weights. Its Breakout network uses only 6 and 8 of the hidden units and reads 208 of the 600 inputs.

Tracr builds a new shape for each program. Every program becomes a transformer of 7 to 11 layers, each an attention block followed by an MLP, and every layer runs at all 107 token positions. At each position a residual stream of 358 to 599 numbers carries the program's values. Most of them are one-hot codes: 106 dimensions say which position it is, 72 say which token, and each categorical value the program computes gets one dimension per possible value. The compiler stores a dense matrix for every block, so the networks have 2.3 to 57 million parameters, of which only 0.04% to 0.22% are nonzero. Astra's networks are 3% to 4% nonzero.

The work per move differs even more than the size. Per move, Breakout's transformer does about 1.3 million multiply-adds with nonzero weights, against 801 for Astra's network: each block runs at every position, and each attention head compares every pair of positions. Counting the zeros Tracr stores, it does 251 million. The program behind it is 120 lines, which Tracr expands into 2.3 million numbers.

Did Tracr compile what Opus wrote?

Tracr can be inexact: its attention is a softmax with finite temperature and its numerical MLPs approximate functions on a grid. So we compared each compiled network with RASP's own reference evaluator, rasp.evaluate, on 256 positions from the network's own games.

The Breakout program compiles exactly: every logit is defined, the largest difference is 0.0002, and the two policies are identical. Seaquest's RASP fails on only 2 of the 256 positions, where a None reaches an integer division; on the rest the compiled policy differs from the program by a total variation of 0.002. The disagreements in the best action are near-ties.

Asterix is the interesting case. When an attention selects no cell, for example a neighbour off the board, RASP returns None, and None passes through every later operation. The compiled transformer instead carries a zero vector, which behaves like "nothing here". The Asterix program relies on that behaviour, so RASP leaves 99% of its logits undefined. Where RASP does give a value, it matches the compiled network to within 0.008. None of the three programs used the stronger tricks seen in our multi-turn Go runs, where writers turned selector predicates into real-valued attention scores that rasp.evaluate rejects outright.

Why Seaquest and Asterix fell short

A weak score could mean the program misread the game, or that compilation broke it. Neither is the case. The Seaquest program reads the oxygen and diver gauges correctly, never runs out of oxygen and surfaces with divers about twice per episode. Per step, both programs score about as fast as Astra's networks: 0.049 against 0.061 points in Asterix, and 0.043 against 0.038 in Seaquest. What differs is how long they live.

To see what kills them, we replayed 100 episodes per network. At every death we tried each action on a copy of the game to see whether any would have survived that step.

Both programs give every safe move the same base score, and their bonuses rarely apply, so the softmax spreads probability almost evenly and the player wanders. A wandering player is often in a spot where replaying its previous move would be fatal. Astra's networks behave differently: they hold one safe default action most of the time and move only up or down. In Seaquest and Asterix, Astra's replies also say so directly: they stay in one column and model sticky movement.

What to keep in mind

  • Each game is one reply, so each result is a sample of one. A second reply could land elsewhere, in either direction.
  • The PPO baselines are the paper's numbers; their checkpoints are not released. Our re-scoring of Astra's networks matches the paper's within noise, which supports comparing against them.
  • The transformer sees the same information as Astra's MLP, encoded as one token per cell instead of 600 separate inputs.
  • Opus's prompt was longer, because it includes Tracr's source. Without it, Opus would have had to recall the compiler's rules from memory.
